# 标准88维 Functionals补充实验

运行：

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 .venv-q1/bin/python -m q1.analysis.functionals88 --threads 2
```

输出到 `outputs/q1/analysis/functionals88/`，不修改主特征或已有 `probe_v2` 结果。

三套输入固定为标准整段88维、自定义整段LLD均值/标准差50维、已有词区间汇总50维。所有样本保留；数字静音的全部声学坐标设为缺失，仅使用各训练折的统计量填补。88维原始输出另行保存。

沿用原探针的37折按视频留一、内层5折分组调参、17档alpha、499次组内置换及2000次视频级成对Bootstrap。独立声学家族在训练折内标准化后除以维度平方根。新加入两套配置，原有17套配置与新增2套共同构成19项Holm校正家族。全部比较是既有实验之后的探索性补充。

标准88维与整段50维覆盖相同音频，但统计定义不同；标准88维与词级50维还改变了时间覆盖及读出权重。本实验不评估词边界准确率，也不自动改变正式768/818/56维输出。
